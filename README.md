# -Sistema-Automatizado-de-Gesti-n-de-Datos-en-Excel
Sistema desarrollado en Microsoft Excel para el registro, procesamiento, limpieza y consulta de datos mediante automatización con VBA, Power Query y funciones avanzadas de Excel.

🚀 Descripción del Proyecto

Este proyecto simula un sistema interno de gestión utilizado para registrar información, procesarla automáticamente y realizar consultas dinámicas desde una interfaz interactiva desarrollada en Excel.
El sistema fue construido siguiendo una arquitectura de flujo de datos:

Entrada de Datos → Procesamiento → Consulta y Control

🛠️ Tecnologías y Herramientas Utilizadas

-Microsoft Excel
-VBA (Visual Basic for Applications)
-Power Query
-Tablas Dinámicas
-Funciones avanzadas de Excel (Filtrar,Elegir columnas,Unicos)
-Validación de Datos

📝 Formulario Automatizado
-Registro de información mediante interfaz visual.
-Botones programados con macros VBA.
-Generación automática de IDs únicos.
-Validación y limpieza automática de campos.

🗂️ Gestión de Base de Datos

-Almacenamiento de registros en tablas estructuradas.
-Registro independiente de observaciones relacionadas a cada compra.
-Organización  de la información.

🧹 Limpieza y Transformación de Datos

Implementación de procesos ETL básicos utilizando Power Query:

-Limpieza de datos
-Transformación de formatos
-Normalización de información
-Generación de tabla final limpia para consultas

🔍 Sistema de Consultas Dinámicas

Desarrollo de una interfaz de búsqueda utilizando funciones avanzadas de Excel:

Funciones utilizadas:

-BUSCARV
-FILTRAR
-ELEGIRCOLS / ELEGIRCOLUMNAS
-ÚNICOS
-CONTARA
-SUMA

Características:
-Consulta de registros por ID
-Extracción dinámica de información
-Listados automáticos
-Conteo de registros
-Resumen de productos únicos
-Visualización de pedidos completados
