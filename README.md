# -Sistema-Automatizado-de-Gesti-n-de-Datos-en-Excel
Sistema desarrollado en Microsoft Excel para el registro, procesamiento, limpieza y consulta de datos mediante automatización con VBA, Power Query y funciones avanzadas de Excel.

🚀 Descripción del Proyecto

Este proyecto simula un sistema interno de gestión utilizado para registrar información, procesarla automáticamente y realizar consultas dinámicas desde una interfaz interactiva desarrollada en Excel.
El sistema fue construido siguiendo una arquitectura de flujo de datos:

Entrada de Datos → Procesamiento → Consulta y Control
